= Open Standards Map
:toc: left
:toclevels: 3
:icons: font

GSBot is built on — and publishes data against — open standards wherever
practical, so it can interoperate across fashion, textiles, regulatory
and supply-chain systems without proprietary lock-in.

Legend: ✅ = in use today; 🧪 = planned / piloting; 🔭 = investigating.

== Adding / Updating Standards

Proposals for new standards go through:

. An issue tagged `standards` with motivation and mapping to the
   existing triple-bottom-line axes.
. A short section in this document (link:STANDARDS.adoc[]) with the
   status marker (✅ / 🧪 / 🔭).
. Where the standard touches the scoring kernel, a property-based test
   in `echidna` is added before it becomes ✅.

== Cross-Industry Rationale

Fashion/textiles is only one vertical.  The standards choices here are
deliberately *horizontal* — nothing about the scoring kernel, the
ontology, or the feed architecture is fashion-specific.  Future
verticals (interior textiles, PPE, automotive fabrics, packaging)
reuse the same primitives: material records, impact vectors, supplier
identifiers, and Pareto trade-off surfaces.
